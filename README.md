# Help 엑셀·한글 (Help Excel·Hangul)

**엑셀·한글 업무 중 발생하는 문제를 AI로 해결하고, 채택된 해결 사례와 유용한 업무 서식을 함께 활용하는 웹 기반 업무지원 시스템**

## 1. 접속 주소 및 실행 환경

- **서비스 접속:** https://helpexcel.vercel.app/
- **자료 공유 화면:** https://helpexcel.vercel.app/share.html
- **실행 방법:** 인터넷이 연결된 PC에서 웹브라우저로 접속합니다.
- **운영체제:** 특정 운영체제 전용 프로그램이 아닌 웹 서비스입니다. Windows PC에서 이용할 수 있습니다.
- **권장 브라우저:** Microsoft Edge 또는 Google Chrome.
- **설치:** 이용자 PC에 별도 프로그램 설치나 로그인이 필요하지 않습니다.
- **권장 사양:** 최신 웹브라우저를 실행할 수 있는 일반 사무용 PC와 안정적인 인터넷 연결.

> 본 프로젝트는 별도의 `.exe` 실행파일을 제공하는 설치형 프로그램이 아닙니다. GitLab/GitHub에 등록한 웹 화면 파일과 `api/` 서버 API를 Vercel에 배포하여 실행합니다. `public/index.html`만 PC에서 직접 열면 AI 답변·Notion 조회 등 서버 기능을 정상적으로 이용할 수 없습니다.

## 2. 주요 기능

| 기능 구분 | 주요 내용 |
| --- | --- |
| AI 질문·답변 | 엑셀·한글 사용 중 발생하는 오류, 함수·서식 작성, 문서 처리 등에 대해 자연어로 질문하고 해결 방법 확인 |
| 이미지·파일 첨부 | 오류 화면 캡처 또는 이미지·XLSX·XLSM·CSV·HWPX·PDF 등 지원 파일을 질문과 함께 제출하여 분석 요청 |
| 표·그래프 생성 | 요청에 따라 표·그래프를 생성하고, 지원되는 결과를 CSV·SVG 형식 등으로 다운로드 |
| 해결 답변 채택 | 문제가 해결되면 **‘해결됐어요’**를 선택하여 해당 질문·답변의 저장 요청 |
| 공동 지식 DB | 채택된 해결 사례를 Notion 기반 DB에 축적하고, 유사 질문에 대한 AI 답변 생성 시 참고자료로 활용 |
| 서식·자료 공유 | 엑셀·한글 서식과 업무자료를 등록하고, 등록 자료를 검색·조회하여 업무에 활용 |

**특징:** AI 모델 자체를 재학습하는 방식이 아니라, 사용자가 채택한 해결 사례를 저장하고 관련 사례를 새 질문의 참고자료로 재활용하는 구조입니다. 사례 축적만으로 정확도 향상이 보장되는 것은 아닙니다.

## 3. 실행·작동 방법 (처음 이용하는 경우)

1. **사이트 접속:** 웹브라우저에서 https://helpexcel.vercel.app/ 에 접속합니다.
2. **질문 화면 확인:** 첫 화면의 왼쪽 **‘질문이나 자료를 등록하세요.’** 영역을 사용합니다. 자료 공유 화면에 있다면 상단 **‘AI 질문·답변’**을 클릭하여 돌아옵니다.
3. **질문 입력:** 왼쪽 **‘문제 내용과 첨부 파일’** 입력란에 엑셀·한글 관련 문제 또는 원하는 작업을 작성합니다. 필요한 경우 **‘파일 선택’**으로 이미지·문서 파일을 첨부합니다.
4. **답변 생성:** 왼쪽 하단 **‘답변을 알려줘!’** 버튼을 클릭합니다.
5. **답변 확인:** 오른쪽 **‘답변을 확인하세요!’** 영역에서 AI가 생성한 해결 방법과 작업 결과를 확인합니다. 필요하면 **‘해결 팁 찾기’**에서 기존 해결 사례를 참고합니다.
6. **답변 채택:** 안내된 방법으로 문제가 해결되었다면 **‘해결됐어요’**를 선택합니다. 저장 기능이 정상 연결된 환경에서는 채택된 질문·답변이 공동 지식 DB에 등록됩니다.
7. **표·그래프 요청:** 질문란에 ‘연도별 매출액을 막대그래프로 작성해 줘’와 같이 요청합니다. 오른쪽 답변 영역에서 결과를 확인하고 제공되는 다운로드 버튼을 이용합니다.
8. **자료 공유:** 상단 **‘자료 공유’**를 클릭하면 **‘서식·자료 공유’** 화면으로 이동합니다. 검색창·파일 종류 필터로 자료를 찾고, 파일명을 클릭하거나 **‘상세’** 버튼으로 정보를 확인합니다. 자료를 추가하려면 **‘+ 자료 등록’**을 사용합니다.

> 자료 공유 화면에 목록이 보이더라도 **‘용량 미확인’**, **‘다운로드 수 미집계’** 등으로 표시된 항목은 원본 파일의 저장 여부를 확인해야 합니다. Notion의 목록 정보 등록과 실제 첨부파일 저장은 별개의 작업입니다.

## 4. 시연용 질문 및 데이터

실제 개인정보·비공개 행정자료가 포함되지 않은 예시를 사용합니다.

- **기능 ① 오류 해결:** ‘엑셀에서 VLOOKUP 함수 사용 시 #N/A 오류가 발생합니다. 원인과 해결 방법을 알려줘.’ → 답변 확인 → 해결 시 ‘해결됐어요’ 선택.
- **기능 ② 서식 작성:** ‘엑셀에서 특정 조건에 해당하는 행만 색상을 표시하는 조건부 서식 설정 방법을 알려줘.’ → 단계별 안내 확인.
- **기능 ③ 표·그래프 생성:** ‘2024년 120, 2025년 150, 2026년 180인 매출액을 연도별 막대그래프로 작성해 줘.’ → 결과 확인 → 제공되는 다운로드 기능 확인.
- **기능 ④ 파일 분석:** 개인정보를 제거한 샘플 XLSX 또는 CSV를 첨부하고 ‘첨부 자료를 요약하고 주요 특징을 분석해 줘.’라고 요청.
- **기능 ⑤ 자료 공유:** 상단 ‘자료 공유’ → 기존 등록 자료 검색·상세정보 확인 → 공개 가능한 샘플 서식 등록 시연.

> 저장소에 별도 시연용 XLSX·HWPX 파일이 포함되어 있는지는 확인이 필요합니다. 실제 직원 정보나 비공개 문서는 공개 저장소 및 외부 AI 서비스에 업로드하지 마세요.

## 5. AI(LLM) 및 공동 지식 DB 연결 설정

- **AI 제공자:** Google Gemini. 모델 ID는 Vercel의 `GEMINI_MODEL` 설정값을 사용합니다. 확인한 코드 버전의 기본값은 `gemini-3.1-flash-lite`이며, 실제 운영 모델은 배포된 코드와 환경변수에 따라 달라질 수 있습니다.
- **AI 호출 파일:** `api/assist.js` (Vercel 서버 API).
- **API 키 등록:** Vercel 프로젝트 → **Settings → Environment Variables**에서 `GEMINI_API_KEY`를 등록하고 재배포합니다.
- **모델 변경:** 같은 화면에서 `GEMINI_MODEL`에 사용할 Gemini 모델 ID를 지정하고 재배포합니다. 사용 가능한 모델 ID와 API 권한을 확인해야 합니다.
- **Notion 연결:** `NOTION_TOKEN`, `NOTION_PROBLEMS_DATA_SOURCE_ID`를 Vercel 환경변수에 등록하고, 해당 데이터베이스/데이터 소스에 Notion 통합 연결 권한을 부여합니다.
- **답변 채택 검증:** `FEEDBACK_SIGNING_SECRET`을 설정합니다. 답변 채택 시 서버에서 확인 토큰을 검증하는 용도로 사용합니다.
- **공유파일 저장(해당 기능 사용 시):** Supabase 연동에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 등의 설정이 필요할 수 있으며, 배포 버전에 따라 추가 보안 설정을 확인해야 합니다.

**보안:** API 키와 비밀 토큰은 GitLab/GitHub 저장소, `public/` 폴더, README에 직접 입력하지 않습니다. 실제 비밀값은 Vercel 환경변수에만 등록합니다.

## 7. 확인된 제약 및 주의사항

- AI 답변은 항상 정확한 것은 아니므로 중요한 수식·수치·행정문서는 사용자가 최종 검토해야 합니다.
- 이미지·문서 첨부는 파일 형식과 내용에 따라 분석이 제한될 수 있습니다. 특히 복잡한 HWPX 서식, 이미지 중심 문서 등은 결과를 확인해야 합니다.
- 채택 사례는 AI 모델을 자동 재학습시키는 데이터가 아니라, 이후 유사 질문에 활용하는 참고자료입니다.
- Notion 연결이나 API 권한 설정에 오류가 있으면 해결 사례 저장·조회 또는 공유자료 목록 표시가 실패할 수 있습니다.
- 공유자료 목록에 파일명이 표시되어도 실제 원본 파일이 별도 저장소에 업로드되지 않았다면 다운로드가 불가능할 수 있습니다.
- 비공개 행정자료·개인정보는 첨부 전에 제거하거나 비식별 처리해야 합니다.
- 인터넷 연결, Gemini API, Vercel 서버 API 및 Notion 등 외부 서비스의 정상 동작이 필요합니다.

## 8. 개발 배경 및 기대효과

공무원은 공문서·보고서 작성, 자료 취합, 통계 분석 등 일상적인 업무에서 한글과 엑셀을 자주 사용합니다. 그러나 함수·서식 오류, 표·그래프 작성 등에서 문제가 발생하면 인터넷 검색이나 동료 문의를 통해 해결 방법을 찾느라 시간이 소요됩니다. 해결 방법이 개인에게만 남아 유사한 문제를 다시 검색해야 하는 경우도 많습니다.

**Help 엑셀·한글**은 이러한 문제를 AI로 신속하게 해결하고, 사용자가 채택한 해결 사례를 공동 지식 DB에 축적하여 다른 직원도 참고할 수 있도록 개발한 시스템입니다. 또한 유용한 엑셀·한글 서식과 작성 사례를 공유하여 **보고서와 행정문서의 품질 및 완성도 향상**을 지원합니다.

이를 통해 반복적인 문제 해결 시간을 줄이고, 개인의 업무 경험을 조직의 공동 지식으로 활용하며, 행정업무의 효율성과 문서 작성 품질을 함께 높이고자 합니다.
